Dopplers fœtaux

Méthode : percentiles calculés à partir des références FMF de Ciobanu et al. 2019, avec application des précisions méthodologiques de Wright et al. 2021. Le CPR est calculé automatiquement par IP ACM ÷ IP AO. Code couleur : vert si normal ; rouge si IP AO > P95 ou percentile affiché du CPR < P5.

Référence : Ciobanu A, Wright A, Syngelaki A, Wright D, Akolekar R, Nicolaides KH. Fetal Medicine Foundation reference ranges for umbilical artery and middle cerebral artery pulsatility index and cerebroplacental ratio. Ultrasound Obstet Gynecol. 2019;53:465–472. Application selon Wright et al., 2021 (Reply, doi:10.1002/uog.23579).
