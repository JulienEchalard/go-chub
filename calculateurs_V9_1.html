Hadlock HC–PA–LF

Dopplers fœtaux

Calcul natif GO-CHUB : les percentiles sont calculés à partir des références FMF. Le CPR est calculé automatiquement par IP ACM ÷ IP AO. Code couleur : vert si normal ; rouge si IP AO > P95 ou percentile affiché du CPR < P5.

Référence : Ciobanu A, Wright A, Syngelaki A, Wright D, Akolekar R, Nicolaides KH. Fetal Medicine Foundation reference ranges for umbilical artery and middle cerebral artery pulsatility index and cerebroplacental ratio. Ultrasound Obstet Gynecol. 2019;53:465–472. Méthode de calcul des percentiles clarifiée par Wright et al., 2021.
